# KMC Portable Conveyor Belt Weighing Systems

A professional website for KMC group's innovative portable conveyor belt weighing systems using laser array technology.

## 🎯 About

This website showcases KMC group's cutting-edge conveyor belt weighing solutions featuring:

- **Portable/Static Laser Array Systems** - No conveyor belt modifications required
- **Zero-Contact Design** - Non-intrusive measurement technology
- **Easy Deployment** - Quickly deployable by hand or single operator
- **Open-Source Components** - All parts except our Converter module are off-the-shelf and easily obtainable
- **Remote Monitoring** - Remotely monitor and calibrate from any location

## 🚀 Quick Start

1. Clone the repository
2. Open `index.html` in your web browser to view the site
3. All pages are static HTML/CSS - no build process required
